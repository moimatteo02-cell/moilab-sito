# Istruzioni per agenti di coding

- Leggi `README.md` e le istruzioni pertinenti prima di modificare il sito.
- Per ogni attività di progettazione o modifica del sito che riguarda interfaccia, immagini inserite in una UI, layout, componenti, sfondi, animazioni o interazioni, segui `docs/react-bits.md`: consulta il catalogo React Bits aggiornato, valuta i componenti pertinenti e riusa prima i porting già presenti.
- Il sito è statico in HTML/CSS/JavaScript e non usa una build. Mantieni lo stack esistente; non aggiungere framework o dipendenze pesanti senza averne spiegato necessità e impatto.
- Preserva lo stile MOI LAB, il comportamento mobile, tastiera/touch e le regole di movimento ridotto.
- Rispetta il flusso Git del progetto: lavora sulla branch `anteprima`; `main` è il sito pubblico e non va modificata senza l'esplicito «pubblica» dell'utente.
- Non sovrapporre modifiche alla stessa pagina con un altro agente: controlla il lavoro recente e coordina il passaggio di mano come descritto nel README.
